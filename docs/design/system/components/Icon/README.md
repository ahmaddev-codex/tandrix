# Icon

Icons are line glyphs on a 24-unit grid with a 1.5 stroke, round caps and joins, matching Lucide geometry.

- **Sizes:** 16px inside chips and small buttons, 20px in cards and `lg` buttons, 24px in `field` buttons.
- They take `currentColor`, so they inherit the text colour they sit with.
- Decorative icons are hidden from assistive tech. Give an icon `label` only when it stands alone.
- Use the Lucide icon set for any glyph not in this bundle (`lucide-react` on the Mac and web, `lucide-react-native` on the phone), at the same stroke.
