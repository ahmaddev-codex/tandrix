# LensCard

LensCard is the step shown on the Ray-Ban Display lens. The lens adds light, so `lens-ground` black is see-through and only the text shows.

- One step: the number in `lens-accent`, the text in `lens-20` in `lens-ink`, and one spoken-command hint.
- Two lines at most; speech carries the rest.
- No images, highlights or colour fills on the lens. The highlight stays on the phone screen.
- **Provide:** `step`, the step text as children, and `hint`.
